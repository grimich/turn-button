Prompt Spur support

Prompt Spur adds a boot-shaped shortcut next to Send on ChatGPT's message composer.

  • The button appears when the composer is visible.
  • It is disabled while the composer has draft text, so it cannot overwrite a draft.
  • Open the extension's Options page to change the text it sends. The default is turn.

If the button does not appear, refresh the ChatGPT tab and check that the extension is enabled in chrome://extensions.
