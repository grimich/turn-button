# Chrome Web Store privacy declarations

## Single purpose

Add one boot-shaped shortcut beside ChatGPT Send that inserts and sends a user-selected short message.

## Data usage answers

Declare **No** for every data collection and data sharing category. The chosen message is saved only in Chrome's local extension storage; Prompt Spur never collects or transmits it. It does not collect or transmit personal information, website content, authentication information, browsing activity, financial information, location, health information, or user communications.

## Justification for host access

The extension runs only on `https://chatgpt.com/*`. It adds the button to the existing composer and triggers the existing Send control after the user clicks it. No conversation text is read or retained.

## Remote code

None. All executable code is inside the uploaded ZIP.

## Advertising

None.
