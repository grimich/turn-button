## Short description

A boot-shaped ChatGPT shortcut. Sends `turn` by default; set any text in Options.

## Detailed description

Prompt Spur puts one compact boot button beside ChatGPT's normal Send control.

When the composer is empty, click the button and ChatGPT sends the configured text using its usual interface. The default is `turn`. Open the extension's Options page to choose your own text; it is saved only in local Chrome extension storage.

Prompt Spur runs only on `chatgpt.com`. It has no popup, background worker, analytics, external network requests, remote code, or account system. It does not read or retain conversation content.

Prompt Spur is independent software and is not affiliated with or endorsed by OpenAI or ChatGPT.
